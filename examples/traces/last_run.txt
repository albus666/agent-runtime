What I changed:

**`hello.py`** — replaced the old `add` function with a minimal bubble sort:
```python
def bubble_sort(a):
    a = list(a)
    for i in range(len(a)):
        for j in range(len(a) - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a
```
It copies the input (`list(a)`) so the caller's list isn't mutated, and the inner loop shrinks by `i` each pass since the tail is already sorted.
